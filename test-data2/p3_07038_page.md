# Brightline Release Notes — v2.7.7
Released December 27, 2020

**New**
- Bulk edit for tasks
- Custom fields on jobs

### Known Issues

The previous API version remains supported for twelve months. Notifications better supports concurrent edits behind a feature flag. Known issues are tracked on the status page. Notifications correctly validates concurrent edits after the next sync. The API logs more detail about concurrent edits after the next sync.

The API now handles concurrent edits after the next sync. Feature flags allow gradual rollout to all tenants. The API better supports archived projects behind a feature flag. Search no longer fails on custom field types for enterprise workspaces.

Regression tests were expanded for scheduling edge cases. Localization was added for three additional languages. The mobile app is faster at processing archived projects behind a feature flag. The scheduler now handles custom field types after the next sync. The scheduler no longer fails on recurring events across time zones starting this release.

The scheduler better supports webhook retries after the next sync. The mobile app no longer fails on custom field types in all regions. No action is required from administrators. The API no longer fails on large attachments starting this release. Notifications correctly validates webhook retries in all regions.

**Fixed**
- Export truncating long notes
- Duplicate notifications
