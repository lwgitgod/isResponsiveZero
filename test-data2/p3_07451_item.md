# Brightline Release Notes — v4.16.0
Released the 15th day of February, 2022

**New**
- Bulk edit for tasks
- SAML SSO

**Fixed**
- Timezone bug on recurring events
- Duplicate notifications

The previous API version remains supported for twelve months. Deprecated endpoints now return a warning header. Localization was added for three additional languages. Search better supports custom field types starting this release.

Search correctly validates recurring events across time zones after the next sync. The scheduler correctly validates webhook retries behind a feature flag. Regression tests were expanded for scheduling edge cases. The admin console better supports webhook retries behind a feature flag. The mobile app correctly validates custom field types after the next sync.

The admin console better supports CSV files with unusual encodings on supported browsers. The scheduler logs more detail about concurrent edits for enterprise workspaces. Feature flags allow gradual rollout to all tenants.

The scheduler now handles CSV files with unusual encodings in all regions. Logs are retained for ninety days. Notifications now handles large attachments for enterprise workspaces. The API logs more detail about bulk updates on supported browsers. Exports correctly validates recurring events across time zones for enterprise workspaces.

The API correctly validates concurrent edits behind a feature flag. Search now handles large attachments behind a feature flag. The mobile app now handles webhook retries for enterprise workspaces. The import wizard logs more detail about archived projects for enterprise workspaces.
