## Brightline Release Notes — v3.12.7
Released 2023-06-03

**New**
- Webhook retries
- Custom fields on jobs

### Notes

The import wizard logs more detail about webhook retries behind a feature flag. Search logs more detail about custom field types after the next sync. Deprecated endpoints now return a warning header.

The scheduler correctly validates archived projects starting this release. The mobile app is faster at processing concurrent edits behind a feature flag. Notifications now handles large attachments after the next sync. The mobile app now handles CSV files with unusual encodings after the next sync. Search is faster at processing large attachments in all regions.

The API better supports concurrent edits in all regions. The scheduler now handles concurrent edits in all regions. Exports no longer fails on bulk updates on supported browsers. Exports now handles CSV files with unusual encodings behind a feature flag.

The previous API version remains supported for twelve months. Search no longer fails on custom field types after the next sync. Performance improvements apply to all workspaces automatically.

The API now handles concurrent edits for enterprise workspaces. Search is faster at processing archived projects starting this release. The scheduler correctly validates bulk updates for enterprise workspaces. Notifications is faster at processing CSV files with unusual encodings behind a feature flag. The scheduler logs more detail about webhook retries starting this release.
