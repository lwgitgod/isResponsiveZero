# Brightline Release Notes — v3.9.0
Released March 11, 2023

**New**
- Bulk edit for tasks
- SAML SSO

**Fixed**
- Export truncating long notes
- Mobile crash on Android 12

### Other Changes

Deprecated endpoints now return a warning header. The scheduler better supports custom field types after the next sync. The scheduler logs more detail about recurring events across time zones starting this release.
