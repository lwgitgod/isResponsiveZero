# Brightline Release Notes — v3.1.9
Released the 5th day of October, 2024

**New**
- Dark mode
- Calendar sync with Outlook

**Fixed**
- Export truncating long notes
- Mobile crash on Android 12

### Notes

The mobile app now handles CSV files with unusual encodings in all regions. The API now handles webhook retries after the next sync. Logs are retained for ninety days. The API correctly validates concurrent edits in all regions. Accessibility fixes were made to keyboard navigation.

The admin console logs more detail about webhook retries on supported browsers. The admin console better supports custom field types behind a feature flag. Notifications now handles webhook retries in all regions.

Notifications better supports recurring events across time zones starting this release. The import wizard logs more detail about custom field types in all regions. The import wizard logs more detail about concurrent edits after the next sync. Search no longer fails on archived projects behind a feature flag. The import wizard now handles custom field types after the next sync.

Search no longer fails on CSV files with unusual encodings starting this release. The scheduler logs more detail about CSV files with unusual encodings in all regions. The scheduler no longer fails on concurrent edits on supported browsers.
