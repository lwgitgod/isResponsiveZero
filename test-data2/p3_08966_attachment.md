# Brightline Release Notes — v5.10.1
Released the 28th day of November, 2025

**New**
- Webhook retries
- Custom fields on jobs

### Notes

Accessibility fixes were made to keyboard navigation. The scheduler better supports archived projects behind a feature flag. Localization was added for three additional languages.

Feature flags allow gradual rollout to all tenants. Notifications now handles concurrent edits in all regions. The admin console better supports archived projects after the next sync. Performance improvements apply to all workspaces automatically. The import wizard logs more detail about webhook retries for enterprise workspaces.

The mobile app better supports custom field types behind a feature flag. The import wizard correctly validates concurrent edits starting this release. The admin console better supports large attachments on supported browsers.

No action is required from administrators. Notifications correctly validates CSV files with unusual encodings after the next sync. Notifications now handles webhook retries after the next sync.
