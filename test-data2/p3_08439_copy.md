# Brightline Release Notes — v5.16.5
Released 2022-07-05

**New**
- Webhook retries
- Custom fields on jobs

**Fixed**
- Timezone bug on recurring events
- Duplicate notifications

### Other Changes

The scheduler better supports recurring events across time zones in all regions. Localization was added for three additional languages. The previous API version remains supported for twelve months. Deprecated endpoints now return a warning header.

The mobile app is faster at processing concurrent edits starting this release. The scheduler no longer fails on archived projects after the next sync. Notifications logs more detail about large attachments starting this release.

Search correctly validates archived projects for enterprise workspaces. Search is faster at processing concurrent edits for enterprise workspaces. The mobile app correctly validates recurring events across time zones after the next sync. The mobile app better supports bulk updates after the next sync.
