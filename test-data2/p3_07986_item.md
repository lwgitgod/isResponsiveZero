# Brightline Release Notes — v2.16.1
Released 8/2/2020

**New**
- Dark mode
- Custom fields on jobs

Deprecated endpoints now return a warning header. The import wizard better supports CSV files with unusual encodings for enterprise workspaces. Feature flags allow gradual rollout to all tenants.

Search logs more detail about custom field types in all regions. No action is required from administrators. The mobile app is faster at processing recurring events across time zones on supported browsers.

The import wizard correctly validates custom field types in all regions. Localization was added for three additional languages. Search is faster at processing large attachments after the next sync. The import wizard logs more detail about bulk updates after the next sync.

The import wizard logs more detail about concurrent edits in all regions. Performance improvements apply to all workspaces automatically. The import wizard no longer fails on large attachments starting this release.
