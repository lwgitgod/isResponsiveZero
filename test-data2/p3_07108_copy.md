# Brightline Release Notes — v2.2.0
Released November 23, 2025

**New**
- CSV import for contacts
- SAML SSO

### Other Changes

Accessibility fixes were made to keyboard navigation. Search now handles archived projects behind a feature flag. No action is required from administrators. The API better supports large attachments for enterprise workspaces.

Search correctly validates concurrent edits for enterprise workspaces. The import wizard correctly validates archived projects behind a feature flag. The import wizard no longer fails on webhook retries after the next sync. Deprecated endpoints now return a warning header. Notifications is faster at processing large attachments in all regions.

Logs are retained for ninety days. Search no longer fails on custom field types on supported browsers. The import wizard no longer fails on custom field types starting this release. The scheduler better supports bulk updates starting this release. The admin console better supports concurrent edits on supported browsers.

Notifications is faster at processing concurrent edits on supported browsers. The import wizard no longer fails on custom field types for enterprise workspaces. Exports better supports concurrent edits after the next sync. Known issues are tracked on the status page.

Exports correctly validates archived projects after the next sync. Feature flags allow gradual rollout to all tenants. The scheduler no longer fails on CSV files with unusual encodings behind a feature flag. The scheduler logs more detail about recurring events across time zones starting this release.

**Fixed**
- Slow load on large boards
- Duplicate notifications
