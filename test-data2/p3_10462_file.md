### Other Changes

No action is required from administrators. The API better supports archived projects behind a feature flag. The previous API version remains supported for twelve months. The admin console correctly validates bulk updates on supported browsers.

Notifications logs more detail about recurring events across time zones on supported browsers. Search no longer fails on bulk updates on supported browsers. Regression tests were expanded for scheduling edge cases.

Feature flags allow gradual rollout to all tenants. Search correctly validates webhook retries in all regions. Search correctly validates custom field types behind a feature flag. The import wizard no longer fails on CSV files with unusual encodings after the next sync.

Exports no longer fails on archived projects on supported browsers. The API no longer fails on concurrent edits behind a feature flag. The import wizard better supports custom field types after the next sync. The import wizard now handles bulk updates on supported browsers. Search logs more detail about bulk updates in all regions.

**Fixed**
- Export truncating long notes
- Duplicate notifications
