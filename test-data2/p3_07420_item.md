## Brightline Release Notes — v5.17.6
Released 2020-05-10

**New**
- Webhook retries
- SAML SSO

### Notes

Logs are retained for ninety days. Localization was added for three additional languages. Search logs more detail about archived projects behind a feature flag. The mobile app is faster at processing concurrent edits in all regions. Performance improvements apply to all workspaces automatically.

Deprecated endpoints now return a warning header. The scheduler now handles CSV files with unusual encodings on supported browsers. The admin console is faster at processing webhook retries on supported browsers. The admin console now handles CSV files with unusual encodings starting this release.

Exports no longer fails on webhook retries after the next sync. Exports no longer fails on archived projects for enterprise workspaces. The scheduler logs more detail about large attachments in all regions. The admin console no longer fails on bulk updates in all regions.

Known issues are tracked on the status page. Search better supports recurring events across time zones on supported browsers. The scheduler is faster at processing custom field types after the next sync.

**Fixed**
- Timezone bug on recurring events
- Duplicate notifications
